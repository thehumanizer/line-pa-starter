# line-pa-starter — PA ของเราในไลน์

ผู้ช่วยส่วนตัว (PA) ที่ **ฟังกลุ่มไลน์งาน** เก็บข้อความไว้ที่ส่วนกลาง **สรุปให้เราทุกเช้า** คุยกับเราแบบ 1:1 และให้ PA ใน **Claude Code** ใช้ข้อมูลชุดเดียวกันทำงานต่อ

ตัวตนของ PA (ชื่อ นิสัย วิธีทำงาน) อยู่ในไฟล์เดียว `persona/SKILL.md`

```
กลุ่มไลน์ ──▶ บอทบน Cloudflare (Workers) ──▶ ฐานข้อมูลกลาง (D1)
                     │                              │
                     ▼                              ▼
          สรุปเช้า · คุย 1:1 ในไลน์       MCP line-pa ใน Claude Code
```

## ต้องมีอะไร
- Node.js 20 ขึ้นไป · Claude Code
- บัญชี LINE Official Account ที่เปิด Messaging API แล้ว
- บัญชี Cloudflare (แพ็กเกจฟรีพอ) · AI API key (Gemini ฟรีใช้ฝึกได้ / Claude สำหรับใช้จริง)

## เริ่มใช้ (ประมาณ 15 นาที)
```bash
git clone https://github.com/thehumanizer/line-pa-starter.git
cd line-pa-starter
cp ~/.claude/skills/<ชื่อโฟลเดอร์PA>/SKILL.md persona/SKILL.md   # ใส่ตัวตน PA ของเรา
npm install
npx wrangler login
npm run setup
```
`npm run setup` จะสร้างฐานข้อมูล deploy บอท ให้วางกุญแจ 4 ตัว (Channel secret · Channel access token · Your user ID · AI key) และ **ตั้ง Webhook URL ในไลน์ให้อัตโนมัติ** จบแล้วจะบอกว่ายังต้องกดอะไรเองอีกบ้าง

## ใช้กับ Claude Code (MCP `line-pa`)
เปิด Claude Code ในโฟลเดอร์นี้ (`claude`) ครั้งแรกจะถามให้อนุญาต MCP `line-pa` → กดอนุญาต แล้วคุยได้เลย เช่น

| พูดว่า | Claude ใช้ |
|---|---|
| "บอทเงียบ เป็นอะไร" | `pa_status` เช็คทีละจุดพร้อมวิธีแก้ |
| "ต่อบอทเข้าไลน์ให้หน่อย" | `pa_connect_line` ตั้ง Webhook URL และทดสอบ |
| "ฟังอยู่กี่กลุ่ม" | `pa_groups` |
| "อาทิตย์นี้ลูกค้า A พูดว่าอะไรบ้าง" | `pa_search` ดึงสดจากบอท |
| "ลองสรุปด้วยสูตรใหม่ให้ดูก่อน" | `pa_digest` ดูตัวอย่างโดยยังไม่ deploy |
| `/brain วันนี้มีงานอะไรค้าง` | คำสั่งสำเร็จรูป ค้นแล้วตอบด้วยตัวตน PA |

MCP นี้ **ไม่ถือกุญแจ LINE หรือ AI** — เรียกบอทบน Cloudflare ผ่าน `/admin/*` ด้วยรหัสในไฟล์ `.env.local` เท่านั้น และไม่ใช้ library ภายนอก

## คำสั่งที่ใช้บ่อย
| คำสั่ง | ใช้ตอนไหน |
|---|---|
| `npm run deploy` | แก้ `persona/SKILL.md` `digest-pattern.md` หรือ `wrangler.toml` แล้วอยากให้บอทใช้ของใหม่ |
| `npm run status` | เช็คว่าบอทพร้อมไหม (เหมือน `pa_status`) |
| `npm run logs` | ดู log สด แล้วทักบอท |
| `npm run sync` | ดึงข้อความลงโฟลเดอร์ `brain/` เป็นไฟล์ markdown (เปิดด้วย Obsidian ได้) |
| `npm run setup` | ตั้งค่าใหม่ / เปลี่ยนกุญแจ (ตอบ y เฉพาะกุญแจที่เปลี่ยน) |

ในแชท 1:1 กับบอท: `กลุ่ม` ดูกลุ่มที่ฟังอยู่ · `สรุป` สรุปตอนนี้ · `ลบกลุ่ม <ชื่อ>` ลบข้อมูลกลุ่ม

## ความปลอดภัย
- บอท **ไม่ตอบในกลุ่ม** (โค้ดไม่มีส่วนที่ส่งข้อความเข้ากลุ่มเลย) และตอบ 1:1 **เฉพาะเจ้าของ** (`OWNER_USER_ID`)
- ข้อความจากกลุ่มถูกส่งให้ AI ในฐานะ "ข้อมูล" ไม่ใช่คำสั่ง — มีคนพิมพ์สั่งบอทในกลุ่ม สรุปจะรายงาน แต่ไม่ทำตาม
- ลบข้อความเก่ากว่า `RETENTION_DAYS` (ค่าเริ่มต้น 90 วัน) อัตโนมัติทุกเช้า
- **ก่อนใช้กับแชทงานจริง** เปลี่ยนเป็น AI แบบจ่ายเงิน (Gemini ฟรีอาจนำข้อมูลไปพัฒนาโมเดล) และอย่าใส่ในกลุ่มที่มีลูกค้าหรือคนนอกจนกว่าบริษัทจะตกลงเรื่องการเก็บข้อมูล
- ห้ามเอา `.dev.vars` `.env.local` ขึ้น GitHub (กันไว้ใน `.gitignore` แล้ว)

ติดตรงไหน เปิด Claude Code ในโฟลเดอร์นี้แล้วเล่าอาการ — Claude อ่าน `CLAUDE.md` และรู้จักระบบนี้ทั้งหมด
